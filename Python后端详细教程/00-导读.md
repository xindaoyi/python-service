# 导读：写给会前端的你

这套教程假设你会 Python 基础语法（变量、函数、类、装饰器见过即可）和 Web 前端开发（HTML/JS、发请求、组件化思想），但**没写过后端、没碰过数据库和 Redis**。所以我们从最底层的世界观讲起，并且全程用你熟悉的前端概念做类比。

## 一、前端 vs 后端：你已经会了什么

你写前端时一定做过这样的事：

```js
// 前端：向服务器要数据
const resp = await fetch("https://api.example.com/users/1");
const user = await resp.json();
```

**后端就是 `api.example.com` 背后接收这个请求、查出数据、返回 JSON 的那个程序。** 这套教程就是教你怎么写出这个程序，并让它扛得住真实业务的复杂度。

好消息是，后端的大部分概念都能在前端找到对应物：

| 你已经会的前端概念 | 对应的后端概念 | 相似点 |
|---|---|---|
| Vue Router / React Router（URL → 组件） | FastAPI 路由（URL → 处理函数） | 都是"路径映射到处理者" |
| axios 拦截器（请求/响应统一处理） | 中间件、API 网关 | 在请求必经之路上做统一逻辑 |
| localStorage / sessionStorage | Redis | 都是键值存储，但 Redis 是**服务端共享**的 |
| Promise / async await / 事件循环 | Python asyncio / async await | 语法和思想几乎一模一样 |
| PropTypes / TypeScript interface | Pydantic 模型 | 给数据定义形状并自动校验 |
| 组件拆分（一个页面拆成多个组件） | 微服务拆分（一个系统拆成多个服务） | 都是"高内聚低耦合"的工程实践 |
| npm + package.json | pip + requirements.txt | 依赖管理 |
| webpack 打包出可部署产物 | Docker 构建出可部署镜像 | 把代码和环境打成可交付的包裹 |
| EventEmitter / 事件总线 | 消息队列（RabbitMQ） | 发布-订阅解耦，但 MQ 多了持久化和可靠性 |
| 浏览器同源策略隔离站点 | 容器/服务之间的网络隔离 | 互相访问要走明确的通道 |

学习时每当遇到新概念，先问一句"它像我前端里的什么"，理解会快很多。

## 三、学习建议

1. **所有代码都要亲手敲一遍**，不要复制粘贴。后端的手感是敲出来的。
2. 每个实战后面都有"预期输出"和"常见报错"，先自己跑，对照验证，报错了先查常见报错表。
3. 卡住超过 20 分钟的概念，先跳过做后面的，很多概念会在项目里"第二次相遇"时豁然开朗。
4. 每天的自测清单是底线：能口述出来才算学会，代码跑通只是第一步。

## 四、环境搭建（Day 1 开课前完成）

```bash
# 1. 创建项目目录并进入
mkdir backend-bootcamp && cd backend-bootcamp

# 2. 创建虚拟环境（隔离依赖，类似每个前端项目自己的 node_modules）
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS / Linux

# 3. 安装全部依赖（四天都用得到）
pip install fastapi uvicorn httpx redis sqlalchemy pymysql cryptography pika PyJWT bcrypt

# 4. 用 Docker 启动中间件（Redis、MySQL、RabbitMQ）
docker run -d --name redis -p 6379:6379 redis:7
docker run -d --name mysql -p 3306:3306 -e MYSQL_ROOT_PASSWORD=root123 -e MYSQL_DATABASE=shop mysql:8
docker run -d --name rabbitmq -p 5672:5672 -p 15672:15672 rabbitmq:3-management
```

**没有 Docker 怎么办**：Redis 和 MySQL 都可以装本地版（Windows 直接下安装包，Mac 用 `brew install`）；RabbitMQ 到 Day 4 才用，届时也可用 Docker 桌面版补装。MySQL 实在装不上时，Day 3 前半段可用 SQLite 过渡（改一行连接串），但索引实战还是建议 MySQL。

**验证环境**：下面三条全部通过即就绪——

```bash
python -c "import fastapi, redis, sqlalchemy; print('依赖 OK')"
redis-cli ping          # 返回 PONG
docker ps               # 能看到 redis / mysql / rabbitmq 三个容器
```

准备好了吗？从 [Day 1](Day1-微服务架构.md) 开始。
